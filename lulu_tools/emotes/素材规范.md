# 噜噜表情素材规范（给 Codex / GPT）

分工：GPT 画**静态分层素材**（SVG 优先），Claude 用 `animate_layers.py` 按 `anim.json` 让它动起来，再编码成噜噜屏幕用的 `.eaf`。

---

## 直接复制给 Codex 的提示词

> 你是儿童产品的角色视觉设计师。请为一只桌面机器狗“噜噜”的圆形屏幕设计表情素材。屏幕是 1.09 英寸、240×240 像素的圆屏，就是噜噜的脸，用户是 3～8 岁的柬埔寨小朋友。
>
> 请先定一套统一的视觉风格（配色、眼睛造型、线条粗细），然后按下面“表情清单”逐个出素材。每个表情一个文件夹，里面是**分层的 SVG**（viewBox 一律 `0 0 240 240`，图层之间坐标对齐，透明背景），外加一个 `anim.json` 和一张合成预览 `preview.png`。动画不用你做，你只需按 `anim.json` 的格式写出每个图层该怎么动。
>
> 硬性要求：
> 1. 所有内容放在圆心 (120,120)、半径 108 的圆内（四周留 12px 安全边）
> 2. 小屏幕要一眼看懂：形状粗、对比强，线条宽不小于 6px，最小元素不小于 8px；不要细节纹理、噪点、大面积渐变（屏幕是 8 位调色板，每帧最多 32 种颜色）
> 3. 不要任何文字
> 4. 背景是纯色整圆，用 `anim.json` 的 `bg` 指定，或给一个 `bg.svg`
> 5. 会动的部分拆成单独图层：左眼、右眼、瞳孔、眨眼时的闭眼图、嘴、腮红、每种小装饰（音符、星星、彩纸……）单独一个小 SVG
> 6. 文件名只用英文小写和下划线
>
> 规范全文和示例在附件 `素材规范.md` 和 `example_src/sing/`。

## 一、文件结构

```
emotes_src/
  sing/
    anim.json
    eye_L.svg   eye_R.svg   mouth.svg
    note_gold.svg  note_cyan.svg  note_pink.svg
    preview.png          # 静态合成图，给人看的，可选
  shy/
    ...
```

- **整屏图层**：viewBox `0 0 240 240`，画在它在脸上的真实位置。眼睛、嘴、腮红、眉毛都是这类
- **贴纸图层**：音符、星星、彩纸、心形这类小装饰，单独画，viewBox 随意，透明背景，由 `size` 指定在屏幕上的宽度
- 也可以用 PNG，整屏图层的 PNG 用 960×960，透明背景

## 二、anim.json

```json
{
  "name": "sing",
  "label": "唱歌",
  "frames": 30,
  "fps": 20,
  "bg": "#0C102C",
  "layers": [
    {"src": "eye_L.svg", "move": {"y": 4, "freq": 2}},
    {"src": "eye_R.svg", "move": {"y": 4, "freq": 2, "phase": 0.5}},
    {"src": "mouth.svg", "scale": {"amp": 0.3, "freq": 4}},
    {"sprites": ["note_gold.svg", "note_cyan.svg"], "size": 16,
     "particles": {"count": 3, "from": [190, 196], "to": [206, 76], "wobble": 6, "scale": [0.9, 1.3]}}
  ]
}
```

图层按顺序从下往上画。一个循环是 `frames / fps` 秒（默认 1.5 秒）。所有 `freq` 必须是整数（一个循环里重复几次），这样首尾才能无缝衔接。坐标都是 240×240 屏幕坐标。

### 整屏图层能用的动作（可以组合）

| 字段 | 例子 | 效果 |
|---|---|---|
| `move` | `{"x": 0, "y": 4, "freq": 2, "phase": 0.5}` | 上下/左右来回晃。`"bounce": true` 表示只往上跳 |
| `scale` | `{"amp": 0.1, "freq": 2}` | 一缩一放（±10%），绕图层自身中心；加 `"pivot": [x, y]` 绕指定点 |
| `rotate` | `{"amp": 8, "freq": 1}` 或 `{"spin": 360}` | 来回摆动 ±8 度，或者一个循环转一圈 |
| `opacity` | `{"min": 0.5, "max": 1, "freq": 1}` | 一明一暗（腮红、光晕） |
| `blink` | `{"src": "eye_L_closed.svg", "at": [0.62], "len": 0.08}` | 在循环的 62% 处换成闭眼图，持续 8% |
| `visible` | `[0.3, 0.7]` | 只在这段时间显示 |

### 贴纸图层（`sprites` 列表 + `size` 宽度）

| 字段 | 例子 | 效果 |
|---|---|---|
| `particles` | `{"count": 3, "from": [190,196], "to": [206,76], "wobble": 6, "scale": [0.9,1.3], "spin": 0}` | 沿直线一个接一个飘过去，两头淡入淡出 |
| `orbit` | `{"center": [120,42], "rx": 70, "ry": 14, "count": 3, "spin": 360}` | 绕椭圆转圈（晕头星星） |
| `rain` | `{"count": 22, "area": [20,220], "wobble": 10, "spin": 360, "seed": 7}` | 从上往下飘落（彩纸、花瓣） |
| `twinkle` | `{"points": [[60,50,10],[180,40,12]], "freq": 1}` | 在固定位置一闪一闪，第三个数是大小 |

动作不够用时，在 anim.json 里写 `"note": "希望……"` 描述想要的效果，Claude 会补。

### 原厂 27 个（想统一风格的话一起重画，名字不能改）

`neutral` 平静（要有眨眼）、`happy` 开心、`sad` 难过、`angry` 生气、`surprised` 惊讶、`thinking` 思考、`winking` 眨一只眼、`cool` 酷、`laughing` 大笑、`loving` 喜爱、`crying` 哭、`confused` 困惑、`embarrassed` 尴尬、`sleepy` 困、`confident` 自信、`delicious` 好吃、`kiss` 亲亲、`relaxed` 放松、`shocked` 震惊、`silly` 调皮、`listen` 在听、`scanning` 录制中、`launch` 开机、`calibration` 标定中、`remote_mode` 遥控模式、`nvs_reset` 恢复出厂、`icon_speaker_zzz` 静音

`neutral`、`listen`、`thinking` 是最常出现的三个，最值得花功夫。

## 四、交付后 Claude 做什么

1. 运行 `python animate_layers.py emotes_src out`，生成每个表情的 `.eaf`（屏幕用）和 `.gif`（预览用）
2. 发预览页给你挑，再按意见调动作
3. 把 `.eaf` 放进固件 `main/boards/puppy/emoji/`，新表情加进 `240_240/emote.json`

## 五、限制

- 每个表情 30 帧大约 250～550 KB；资源分区 8 MB，原厂表情约 3.4 MB，新加的总量控制在 4 MB 以内
- 颜色越少、平涂越多，文件越小，播放越流畅
